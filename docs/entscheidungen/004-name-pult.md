# Entscheidung 004: Das Programm heißt Pult

Datum: 2026-10-06 · Status: angenommen (Wahl von Yannik)

## Anlass

Der Arbeitsname "morte" heißt auf Italienisch und Portugiesisch "Tod" (Spanisch "muerte"). Für ein Werkzeug, das Kolleginnen und Kollegen gern öffnen sollen, ist das ungünstig. Vor dem Logo musste der Name feststehen.

## Geprüfte Vorschläge

Kladde, Pult, Lotse, morte behalten. Kurze Websuche am 2026-10-06: Für keinen der Namen gab es eine bekannte Lehrer- oder KI-App. Eine Markenrecherche (DPMA, EUIPO) ist das nicht, sie steht vor einer Veröffentlichung noch aus.

## Entscheidung

**Pult**, wie das Lehrerpult: der eigene, aufgeräumte Arbeitsplatz. Kurz, deutsch, gut als Symbol.

## Folgen

- Oberfläche, PDF-Fußzeile, Begrüßung des Assistenten und Doku heißen "Pult". Der Datenordner ist `~/pult-daten`, die Umgebungsvariablen `PULT_HOME` und `PULT_SKILLS`.
- Übergang: Ein alter Ordner `~/morte-daten` wird beim Start einmal umbenannt. Ein unter "morte" im Schlüsselbund gespeicherter Zugang wird weiter gefunden.
- Das GitHub-Repo heißt noch `morte`. Umbenennen kann es nur der Besitzer.
- Offen: Markenrecherche vor der Weitergabe an Kollegen (Phase 6).

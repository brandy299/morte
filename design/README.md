# Design

Logo, Zeichen und Symbole von Pult. Farben: Terrakotta `#b4532a` und Tinte `#23201b` auf Papier `#f4efe6`. Schriften: Fraunces (Überschriften) und Source Sans 3 (Text), siehe `assets/fonts`. Mehr zur Marke: [docs/marke.md](../docs/marke.md).

| Datei | Verwendung |
|---|---|
| `logo/pult-logo.svg` | Wortmarke auf hellem Grund (README, Oberfläche) |
| `logo/pult-logo-hell.svg`, `logo/pult-logo-einfarbig.svg` | Auf dunklem Grund, einfarbig |
| `logo/pult-zeichen*.svg` | Das „p“ allein, für kleine Flächen |
| `logo/export/` | Fertige Symbole (Favicon, App-Symbol, Touch-Symbol) |
| `social-preview.png` | Vorschaubild für GitHub (1280 × 640). Erzeugt mit `social-preview.mts` |

Die Logos werden mit `logo/build.py` erzeugt.
